# Contributing

Keep changes small and preserve the deployable contract documented in the root
README.

## Where changes belong

| Change | Location |
|---|---|
| Calibration, track, randomization, reward/PPO scalar | `isaac_sim/config/default.json` |
| Simulation behavior, observation/action or reward formula | `isaac_sim/envs/line_following_rl/` and the rendered lane |
| Train/evaluate/export command | `isaac_sim/scripts/` |
| Board pins, capture, telemetry and runtime safety | `firmware/esp32s3_line_following/` |
| Policy weights | generated by the exporter; never edited manually |
| Genuine CAD correction | `linefollowingrobot_cad/` |

Do not commit `.pt`, `.onnx`, generated USD, logs, scenes or debug images. Do
not add seed-specific exceptions, a downstream speed PID, duty boost or a
firmware-only calibration that the simulator did not evaluate.

## Validation

```bash
python tools/project.py doctor
python tools/project.py source-check
python tools/project.py parity
python tools/project.py smoke
```

Changes to perception, plant, timing, ABI or policy require a new BC/PPO run,
rendered gate 0-19, untouched holdout 20-39, regenerated firmware artifacts
and `deployed-smoke`. Run `reference-smoke` only when changing the optional
reference fixture or its loader. Report exact commands, config ranges and
results in the pull request.

Use short imperative commits, for example `vision: retain the last valid
look-ahead` or `sim: calibrate motor breakaway`.

Before a public push, run the additional checks in
[`docs/RELEASE_CHECKLIST.md`](docs/RELEASE_CHECKLIST.md).
